Work in this ISEE Arcade repository must never access or affect anything associated
with KEMPCO (K-E-M-P-C-O) or the FSM/work-order application.

ISEE Arcade work. However, within those accounts, all KEMPCO/FSM projects and
resources remain strictly off-limits.

  keys, and storage;

  build settings;

create, and manage clearly separate ISEE Arcade resources. ISEE Arcade must use
separately named projects, credentials, databases, deployments, and integrations.

ask the user instead.
